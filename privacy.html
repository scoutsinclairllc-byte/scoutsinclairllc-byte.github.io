Hushaby Autopilot: Privacy Policy

Last updated: October 6, 2026

Hushaby Autopilot is an internal tool operated by Scout Sinclair LLC ("we"). It is used only by its owner, to manage the owner's own YouTube channels. It has no other users.

What the tool accesses

With the channel owner's permission (Google sign-in), the tool uses the YouTube Data API and YouTube Analytics API to:

  • read the owner's channel and video statistics (views, watch time, average view duration), and
  • upload videos and thumbnails to the owner's channel.

It does not access any other Google data, and it does not access viewers' personal information.

How data is used and stored

Channel statistics are used only to decide what video to make next. The sign-in token is stored as an encrypted secret in a private GitHub repository controlled by the owner. We do not sell, share or transfer any data to third parties, and we do not use it for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Hushaby Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
